Features

Everything in one launcher

Sign in once, pick a version and play. Eclipse sets up the loader, the mods and the settings for you.

Every version, one click

Vanilla, Fabric, Forge and NeoForge for every Minecraft release, snapshot and old beta. The launcher downloads and installs everything itself.

80 built-in mods

Keystrokes, CPS, FPS and armor HUDs, zoom, freecam, Tier Tagger, totem pop counter, waypoints and many more. Press Right Shift in game, or change the key.

More FPS

Built-in culling skips mobs, chests and signs hidden behind walls. One click on FPS Boost adds Sodium, Lithium, FerriteCore and friends with tuned settings.

Mods, packs and shaders

Search Modrinth for mods, texture packs and shaders. See when updates are out, switch versions, and import Modrinth or CurseForge modpacks.

Skins and capes

A live 3D preview with your real name tag. Upload skins, keep a library, try Minecraft's default skins and switch capes before you play.

Accounts that switch in game

Microsoft and offline accounts, and switch between them from the in-game menu without restarting Minecraft.

Install

Playing in three steps

  1. 1

    Download

    Get Eclipse-Launcher-Setup.exe from the button above. There's also a portable version on GitHub that needs no install.

  2. 2

    Sign in

    Open the launcher and sign in with the Microsoft account that owns Minecraft: Java Edition.

  3. 3

    Play

    Pick a version and a loader and press Play. Eclipse Client is added for you; press Right Shift in game for the mod menu.

Windows may warn about an unknown app the first time (the installer isn't code-signed yet): click More info → Run anyway.

FAQ

Questions

Is it free?

Yes. The launcher and the client are completely free, and the source is on GitHub.

Which versions does it support?

The launcher runs every Minecraft version. Eclipse Client (the in-game mods) works on Fabric 1.8.9–1.12.2 and 1.14.4–26.3, Forge 1.8.9–1.12.2 and 1.18.2–1.20.1, and NeoForge 1.20.2–26.3.

Can I use my own mods and modpacks?

Yes. Drop in your own jars, install from Modrinth, or import a Modrinth (.mrpack) or CurseForge modpack. Eclipse Client works next to Sodium, Iris, Lithium and other popular mods.

Can I use it on servers?

Eclipse Client only changes what you see and your HUD; it adds no cheats. Still, every server has its own rules, so check them if you're unsure.

How do updates work?

The launcher updates itself from GitHub and brings the newest Eclipse Client with it. There's nothing to download again.
